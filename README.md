# Security Architecture Optimizer

Инструмент собирает публичную документацию SIEM и формирует единый каталог
поддерживаемых источников событий, способов сбора, системных требований и
доказательств. Каталог используется для предварительной проверки опросников
организаций.

## Запуск на Windows

Нужны Python 3.10 и доступ к сайтам вендоров. Из корня проекта в PowerShell:

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -c constraints.txt -e ".[ui]"
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run_etl.ps1 -Python .\.venv\Scripts\python.exe
.\.venv\Scripts\python.exe -m streamlit run app.py
```

ETL скачивает документы по [реестру](data/etl/vendors.json) при каждом запуске.
Он создаёт новый каталог `results/runs/` с манифестом, исходными файлами,
каталогом v2 и HTML-отчётом. Скрипт печатает точные пути к каталогу и отчёту.
Интерфейс открывает последний локальный каталог. Для просмотра другого прогона
укажите его папку `catalog` в переменной `SIEM_CATALOG_BUNDLE`.

Код выхода `3` означает, что часть источников недоступна, а каталог собран из
полученных материалов. В отчёте видны пропуски и статусы документов. Доступность
документов и результат извлечения зависят от опубликованных материалов.
Отсутствие сведений само по себе не означает отсутствие поддержки.
