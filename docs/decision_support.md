# Исследовательский прототип выбора SIEM

В `src/siem/core.py` находятся расчёт EPS, предварительный бюджетный фильтр,
взвешенная сумма, TOPSIS и анализ чувствительности. CLI в `src/siem/cli.py`,
интерфейс Streamlit в `app.py`. Данные исходного авторского сравнения сохранены
в `data/reference_metrics.json`; демонстрационный профиль — в `data/demo_infra.json`.

```powershell
python -m siem.cli --method topsis --sensitivity 200
python -m pip install streamlit pandas
streamlit run app.py
```

Исторические оценки, цены и признаки сертификации не подтверждены на текущую дату.
Показатель EPS в исходной таблице нельзя считать технической мощностью без сценария
нагрузки. Выгрузка ETL хранит извлечённые факты отдельно и автоматически не меняет
исходные оценки. Расчёт служит исследовательским примером, а не готовой закупочной
экспертизой.

Проверки расчёта находятся в `tests/test_core.py`. Примеры результатов —
`docs/sample_topsis_result.json`; примеры входов ETL — в `data/examples/`.
