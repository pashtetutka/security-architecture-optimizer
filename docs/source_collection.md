# Происхождение данных

Реестр [официальных документов](../data/etl/vendors.json) задаёт URL, назначение
материалов и адаптеры. Каждый сетевой запуск получает документы заново.
Манифест запуска фиксирует способ получения, URL, состояние загрузки и SHA-256.
Отчёт показывает загруженные и недоступные документы, а также пробелы извлечения.

Источники событий и системные требования извлекаются из HTML, PDF и JSON.
Ссылка на документ и место доказательства входят в нормализованные данные.
Недоступные документы, неизвестные версии и изменение структуры учитываются
при интерпретации результата.
