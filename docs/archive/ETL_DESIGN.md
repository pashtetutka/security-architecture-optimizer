# ETL-подсистема: сбор характеристик SIEM (v0.3)

## Цель
Единый каталог **утверждений о продукте с доказательствами**, а не неформализованная
таблица характеристик. Каждый факт привязывается к SIEM, версии, источнику, дате
и точному объёму утверждения. Автоматически извлечённый факт не означает подтверждённой
работоспособности интеграции и не должен автоматически исключать конкурента.

## Pipeline

1. **Extract**: source-specific adapters. RuSIEM — официальная HTML-страница со списком
   источников; PT — версия справочного портала/локально предоставленный PDF.
2. **Raw**: сохраняем хэш HTML/PDF, дату, URL и короткий извлечённый фрагмент.
3. **Transform**: родительский продукт/подтип -> структурированная запись; явные алиасы.
4. **Validate**: контроль структуры страницы, типы, аномалии и ручная проверка.
5. **Load**: JSON-артефакты; позднее PostgreSQL с историей версий утверждений.
6. **Consume**: сервис сопоставления с источниками предприятия. Отсутствие записи
   не интерпретируется как отсутствие поддержки.

## Поддержка ≠ готовая интеграция

Один источник может поддерживаться разными способами. Для следующих итераций схема
должна различать:
- готовый модуль сбора / штатный протокол / ручную интеграцию;
- парсер / нормализацию / корреляционные правила;
- версию источника и SIEM, лицензии, дополнительные компоненты;
- подтверждение вендором / тест на стенде / отсутствие данных;
- дополнительную стоимость *только при подтверждённой оценке*.

## Уровни достоверности

- `vendor_listed`: официальная страница содержит имя источника, технические детали не подтверждены;
- `candidate_for_review`: ключевая фраза в документации, не готовый структурный факт;
- `manually_verified`: специалист проверил конкретный способ интеграции, источник и версию;
- `lab_validated`: интеграция проверена на тестовом стенде.

Никаких статусов `unsupported` из простого отсутствия совпадения.

## Ограничения

- HTML RuSIEM может измениться — отказ парсера должен создавать задачу на ревью.
- Текущая проверка HTML выполнена на **локальном тестовом фрагменте**, онлайн-загрузка в
  данной среде не была возможна. Запуск по реальному сайту должен быть проверен отдельно.
- Список источников может быть маркетинговой характеристикой, а не гарантией.
- Справочник PT версионный; нельзя смешивать признаки версий 8.0 и 8.6.
- Внешние PDF не включаем в публичный репозиторий: проверять условия использования и права.
- HTML/PDF извлекаем с соблюдением robots.txt и разумной частотой запросов. Для PT
  первый шаг: локальный PDF -> кандидаты -> ручное подтверждение.

## Первая верификация на реальных источниках

RuSIEM: https://rusiem.com/ru/products/parsers — на 2026-10-27 список содержит
`1C 8.3` и `1С Зарплата и управление персоналом`.
PT: https://ptsecurity.com/about/docs/ — официальная документация,
справочник по настройке источников версионный; есть инструкции для `1C:Предприятие 8.3`.
Это **не** является подтверждением отдельного штатного парсера именно для ЗУП в PT.
