# SIEM ETL v0.6 — patch к версии v0.5

Цель: устранить ложные технические требования, образованные текстом в каталогах интеграций, и сделать диагностику качества данных воспроизводимой.

## Изменения

1. Режимы `rvision` и `kuma` извлекают только структурированные строки каталогов. Текст описания источника не превращается в `resources`, `deployment`, `dependencies` и `ha` SIEM.
2. Описание нормализатора KUMA сохраняется как `normalizer_description` в соответствующем структурированном факте.
3. Пустые версии источника (`-`, `—` и т. п.) записываются как `null`, при сохранении оригинального текста в `evidence_excerpt`.
4. `source_version_verified` не заполняется автоматически. Версия, опубликованная в таблице, — пока неподтверждённый факт.
5. Новый `quality --etl`: сводка по состоянию и полноте фактов, версиям, интеграциям.
6. `--manual-dir` для офлайн-обработки законно полученных пользователем HTML/PDF. Путь к файлу: `p03__source_catalog.html` или `p05__product_document.pdf`.
7. Загрузка по сети не отключает проверку TLS и не обходит robots.txt. Если robots.txt недоступен, источник не скачивается и получает статус `robots_unavailable`. Если автоматический доступ запрещён — `access_disallowed`.
8. В выгрузку добавлены `acquisition_method` и `origin_independently_verified=false`, чтобы отличить онлайн-загрузку от тестового и ручного импорта.

## Установка

Перед копированием файлов сохраните локальные изменения Git / сделайте резервную копию.
Распакуйте ZIP в корень вашего проекта, заменяя одноимённые файлы. Запустите:

```powershell
python -m unittest discover -s tests -v
```

Ожидается 42 теста, если код проекта соответствует версии v0.5.

## Проверка без нового сетевого сбора

```powershell
python -m siem.etl.all_cli quality --etl results/vendors_novpn.json
python -m siem.etl.all_cli crawl --replay-from results/vendors_novpn.json --snapshot-dir results/raw --output results/vendors_v06.json
python -m siem.etl.all_cli quality --etl results/vendors_v06.json
python audit_siem_etl.py --etl results/vendors_v06.json
```

Команда replay использует исходные файлы по путям `snapshot_path` в JSON. Путь относительный к корню проекта. Записи, для которых снимки не сохранены, останутся с ошибками; их не следует трактовать как признаки технической несовместимости SIEM.

## Ограничения

- Это патч качества и инструментария, а не новая полная база всех 13 SIEM.
- Все `review_candidate` по-прежнему требуют семантической проверки. Они не должны автоматически превращаться в обязательные требования.
- Автоматическое подтверждение версий SIEM, sizing, бюджета и обязательности компонентов ещё не реализовано.
- Ошибка TLS у MaxPatrol и запрет `robots.txt` у Astra не исправляются отключением проверок: требуется корректный публичный источник или допустимый офлайн-импорт.
