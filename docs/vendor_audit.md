# Состояние ETL по SIEM

Контрольный набор: `data/etl/repro/vendors.json`, режим `--automatic-only`.
Числа относятся к сохранённым документам; полнота всех возможностей SIEM не заявляется.
Каждая запись требует проверки смысла, версии и области применимости перед расчётами.

Уникальных идентификаторов источников: 1165. Число записей больше, поскольку
версии, нормализаторы и способы сбора сохраняются отдельными утверждениями.
Исторические 179 строк частичной поддержки MaxPatrol получены ручным импортом
и исключены из этой таблицы. Их снимки сохранены; см. [source_collection.md](source_collection.md).

ETL готов к воспроизводимой исследовательской обработке этого набора.
Автоматический выбор SIEM и расчёт инфраструктуры требуют следующего этапа
проверки данных, описанного в [roadmap.md](roadmap.md).
