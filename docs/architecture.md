# Архитектура

ETL поддерживает реестр документов для 13 SIEM. Сетевой сбор получает документы
по HTTPS с проверкой TLS и robots.txt. Снимки и их происхождение записываются в
манифест. Офлайн-сборка читает эти снимки по SHA-256 и повторно извлекает факты.

| Слой | Код | Результат |
| --- | --- | --- |
| Сбор и проверка снимков | `src/siem/etl/fetcher.py`, `pipeline.py`, `snapshots.py` | Байты, URL, способ и время получения, SHA-256 |
| Извлечение | `src/siem/etl/adapters.py`, `vendors/` | Записи и диагностика покрытия разделов |
| Канонизация | `src/siem/domain/`, `src/siem/etl/claims.py` | Общие идентификаторы продуктов, версии, единицы и условия |
| Публикация | `src/siem/etl/migration.py`, `bundle.py` | Переносимый каталог `siem-catalog/2.0` |
| Предварительное сопоставление | `src/siem/decision/`, `app.py` | Объяснение покрытия, версий, маршрутов и ограничений для шести организаций |

Каталог v2 содержит утверждения о поддержке, маршруты сбора, системные требования,
профили развёртывания и ссылки на доказательства. Утверждение о сборе имеет свою
область применимости. Возможности нормализации и реагирования проверяются отдельно.
Неизвестные сведения и расхождения остаются в диагностике. Политика зачёта находится
в потребителе каталога.

Пакет состоит из манифеста, JSON-каталога и разрешённых для включения снимков.
Загрузчик проверяет версии схемы, хеши файлов и связи. Windows CI воспроизводит
каталог, сверяет матрицу 23 × 13 и проверяет интерфейс. Команды запуска описаны
в [руководстве ETL](etl.md).
